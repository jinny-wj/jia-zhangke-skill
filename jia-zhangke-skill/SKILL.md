# 贾樟柯 Skill · 时间、空间与普通人

**把普通人的身体与关系，留在正在变化的空间、时间和声音里。**

这句话是本技能的风格归纳。使用公开作品与创作谈形成导演方法，不扮演贾樟柯本人。创作时先看人物怎么工作、移动、相处，再决定怎样拍他。

## 导演底色

| 关心什么 | 在电影里怎样出现 |
| --- | --- |
| 时代如何改变私人生活 | 工作变了、朋友疏远了、家人搬走了，旧有的相处方式逐渐失效 |
| 普通人怎样保住自己的生活 | 找人、挣钱、回家、守住一段关系；人物有体面、欲望、幽默、误判和选择 |
| 故乡、离开与返回 | 身体可以移动，语言、习惯和关系仍带着原来的地方 |
| 变化留下什么痕迹 | 地景、歌声、身体动作、影像载体，成为时间经过的证据 |

下面九项是从不同作品提炼的**风格模型**，不是导演自述的九条公式。S 编号见[来源](references/sources.md)。

## 九个核心风格模型

### 1. 私人关系写出时代

**特点**：社会变化进入友谊、爱情与家庭。观众先认识一个具体的人，再感到他面对的时代。

**银幕表现**：一场见面、一次失联、一份工作的变动，让原本熟悉的人难以继续照旧相处。《小武》《站台》提供不同的私人关系与时代经验。[S1、S6]

**创作抓手**：写人物今天要办的事，以及钱、工时、交通、通讯或居住变化怎样让它变难。让时代通过行动成本进入画面。

### 2. 空间里能看见人的处境

**特点**：人物与地景、建筑、工作场所共同构成叙事。地点的变化会影响身体的路径和关系的去向。

**银幕表现**：《世界》的人造全球景观与劳动者生活，《三峡好人》变化中的奉节与双线寻人，形成不同的空间经验。[S2、S9、S10]

**创作抓手**：先画出门、道路、工作位置和人物的距离。说明他能走到哪里、怎样受阻、哪个旧地点已经不能返回。

### 3. 让生活时间完整经过

**特点**：长镜头保留劳动、闲谈、等待与僵局，让观众与人物一起经历时间。

**银幕表现**：一个动作持续多久，谁先离开，谁仍留在原处，都参与表达。长镜头也给观众在同一画面中自行寻找信息的空间。[S1、S2]

**创作抓手**：镜头里保留可感知的变化：关系不同步、手伸出又收回、环境声改变决定。镜头长度服从这次观察，不规定统一秒数。

### 4. 摄影距离决定如何接近人物

**特点**：现场的贴近感与后退的观察距离都存在，摄影机的立场随作品改变。

**银幕表现**：《小武》采用较多手持，重视事件正在发生的在场感；《站台》以较多远景、全景拉开历史观察距离。[S1]

**创作抓手**：贴近时跟随身体与环境阻碍；退后时让人物、群体和空间同框。把机位写成对人物关系的判断。

### 5. 场内持续，场间省略

**特点**：一场戏里保留生活过程，场与场之间却可以跳过多年。时间的长度与叙事的省略同时存在。

**银幕表现**：《山河故人》通过不同时间段呈现关系的远近与语言变化；缺席的经历允许观众补足。[S3]

**创作抓手**：省略解释性的过程，保留能定位变化的身体、称呼、物件、场所或通讯方式。跳跃之后让关系的结果可读。

### 6. 画外声音带来更大的世界

**特点**：声音有独立结构，画外的公共生活持续进入人物的私人空间。

**银幕表现**：广播、扩音器、劳动声、设备声和环境声，带来记忆、距离与压力。声轨承载的世界可以大于画面。[S1]

**创作抓手**：写明声源来自哪里、人物能否听到、是否因此停步或改变行动。空间可以先被听见，再被看见。

### 7. 歌曲和舞蹈保存公共记忆

**特点**：流行歌舞连接时代经验与个人情绪，也让身体表达难以说出的感受。

**银幕表现**：《站台》《世界》《山河故人》《风流一代》以不同方式使用演出、音乐和身体；歌曲有其所处的时空。[S1、S3、S5、S9]

**创作抓手**：确定谁在听、谁在跳、声音从什么设备传来、再次出现时关系有何变化。欢快、热闹和失落都可以进入同一段经验。

### 8. 媒介本身留下年代痕迹

**特点**：画幅、质感、声音制式与拍摄载体可以参与讲述时间。

**银幕表现**：《山河故人》的分时期影像选择、《风流一代》的多年材料及其载体差异，都让形式保留时间的痕迹。[S3、S4、S5]

**创作抓手**：素材先行时先记录材料的日期、人物、画幅与声音，再寻找情感线。保留差异或统一处理，都要说明叙事用途。

### 9. 现实会变得异样，叙事也会突变

**特点**：现实主义容纳幻想、类型和强冲突，不同作品会改变其表达强度。

**银幕表现**：《世界》《三峡好人》的异样现实，《天注定》的武侠与戏曲思考，《江湖儿女》的类型和动作设计，显示不同路径。[S2、S7、S8]

**创作抓手**：先说明异常或冲突来自哪种生活经验、怎样影响人物，再选择表现方法。普通日常与突然的强度变化都需要人物后果。

## 影像 DNA

| 维度 | 直接写进方案的特点 |
| --- | --- |
| 叙事 | 从找人、工作、回家等具体行动进入，跟随关系的变化与时间的后果 |
| 人物 | 普通人保有自己的价值、欲望和矛盾；生活能力通过行动显现 |
| 构图 | 身体、前后景、群体、门口与行动路径共同表达处境；保留人和环境的关系 |
| 景别与摄影 | 按作品与情境选择现场贴近或远处观察；长镜头、远景、固定机位分别决定 |
| 剪辑 | 镜头内靠走位、视线和声源转移注意力；场间允许时间省略，冲突段落可以改变长短节奏 |
| 声音 | 画内与画外各有任务，广播、劳动声和传播设备让时代进入场景 |
| 音乐 | 与听者、舞者、设备和时期相连；可连接材料、触发记忆或改变情绪 |
| 色彩与质感 | 随场所、媒介和时期变化；舞台色、现场光与数字纹理都有作品依据 |
| 表演与语言 | 写手、身体、呼吸、视线和具体任务；方言、口述、少对白各有适用作品 |
| 结尾 | 本场选择可以完成，关系和人生仍可继续；动作或声响的余留承接变化 |

这张表是综合创作归纳。具体作品的差异见[作品地图](references/film-map.md)，18 个维度的展开见[完整风格库](references/style-atlas.md)。

## 镜头怎样切换

先判断正在观察什么，再选择切换方式：

| 所用方法 | 何时继续观察或切换 | 作品依据 |
| --- | --- | --- |
| 保留完整时间 | 同框的动作、距离或声音仍在变化时继续看；有意义的过程完成后再切 | 《小武》《站台》相关创作谈，S1、S2 |
| 时间省略 | 跳过不必展示的经历，以身体、物件、语言或空间变化承接后果 | 《山河故人》，S3 |
| 音乐连接材料 | 用声轨连接不同年代、画幅与声音制式，形成可跟随的情感旅程 | 《风流一代》，S4、S5 |
| 长短节奏组合 | 根据动作和冲突的信息需要组织镜头，保持整体空间与局部动作可读 | 《江湖儿女》动作设计访谈，S7 |

硬切、声音先行、声音延续、呼应等是可选的实现工具。使用时说明本次切换新增的信息与声画联系；详见[镜头与剪辑](references/shot-editing.md)。

## 原创微例：一次离开怎样被看见

**情境**：曾一起值夜班的人明早去城外的新仓库上班，今晚来店里取走杯子。

**人物行动**：他擦干杯底，把钥匙留在台面上；留下的人习惯性伸向第二只杯子的位置，碰到空处，收回手，继续闭店。

**镜头策略**：同框交代共同空间，近处读清杯子与钥匙，回整体看人怎样离开，再保留留下者的日常。

**声音策略**：门声与画外过车声延续，工作灯仍亮着，人物通过动作完成告别。

这是本技能原创示例。完整的 60 秒剧本与分镜见[《留一盏灯》](references/original-example.md)。

## 使用方法

1. 先确定用户要风格分析、诊断、剧本、分镜还是媒体，以及已有故事与拍摄条件。
2. 选择适合任务的主方法和辅助方法，写清它们怎样作用于人物。无需凑齐九项。
3. 创作时交付人物行动、关系变化、镜头内部变化与声源；需要分镜时标明时长、机位和切点。
4. 只做诊断就保留原文范围。遵守指定主题、人物目标、结局、片长和资源；非关键缺项写明假设后推进。
5. 真实生成按当前工具执行，分清文本方案、实际生成与媒体检查。

## 资料与交付要求

导演表述、作品事实与本技能的分析/迁移分开。上述模型跨作品归纳，使用时保留具体片名和适用情境。史实、地方细节与精确镜头数据按所用版本核实，不编造原话、时码或参数。

交付前检查：人物的事是否读得懂，环境是否影响行动，持续时间里有什么变化，切后新增什么，声源是否清楚，片长和资源是否成立。长镜头、方言、灰色调、废墟和超现实均按任务取用。
