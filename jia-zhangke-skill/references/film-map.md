# 作品差异：持续关心的问题与变化的方法

这是代表作比较，不是全部片目，也不是逐镜头测量。作品信息的出处在 [sources.md](sources.md)；「迁移」一栏是本技能的原创创作建议。

| 作品 | 资料可支持的重点 | 创作迁移 | 避免误归纳 |
| --- | --- | --- | --- |
| 《小武》 | 私人关系在社会变化中失效；摄影强调当下、现场与较多手持。[S1、S12] | 跟随一个具体的人，从朋友、亲密关系、家庭等不同入口展开处境 | 不把现场感归结为纯固定机位，不只写小偷职业符号 |
| 《站台》 | 文工团与演出文化的长期变化；摄影后退，多远景/全景，保持历史距离。[S1、S12] | 用群体日常、演出、衣着、身体和空间变化呈现时间 | 不把十年历史压成讲解旁白，不把远景等同于所有作品 |
| 《任逍遥》 | 数字拍摄、失落青年、流行文化及对未来的想象。[S12、S2] | 看人物借大众文化构想自己，现实行动却受阻 | 数字质感不等于统一加复古颗粒，游荡不等于没有欲望 |
| 《世界》 | 世界公园的人造全球景观与劳动者生活；舞蹈、短信、电子音乐、动画参与表达。[S9] | 让能“看见世界”与实际行动受限并置；需要时让媒介表达内心 | 不把华丽舞台、动画、电子音乐排除在方法之外 |
| 《三峡好人》 | 奉节变化中的双线寻人，环境与家庭关系相互牵动；现实与虚构相连。[S10、S2] | “找到人”不必恢复原关系；行走、停留和劳动承载变化 | 不是只拍废墟；空间剧变必须影响身体与选择 |
| 《二十四城记》 | 真实采访与演员的虚构独白并置，工厂历史进入个人口述。[S11] | 口述、肖像与静默；让措辞和停顿成为可看的变化 | 不统一要求少台词；不把演员独白写成真实证言 |
| 《天注定》 | 四个跨地域故事受现实事件启发，同时借武侠、戏曲等方法虚构化。[S8] | 强冲突也可从具体生活条件出发，类型表达要有后果 | 不能统一归类为无情节、无暴力、只有静止长镜头 |
| 《山河故人》 | 三个时期、迁移与家庭语言变化；画幅、色彩、载体和音乐与时间相连。[S3、S13] | 跨年省略后用身体、语言、物件与场所定位关系；允许鲜明色彩 | 不强制每个项目都改画幅，不只用灰色表达时代 |
| 《江湖儿女》 | 情义、爱情、寻找与归返；导演描述过动作段落的长短镜头设计，跨时期质感也在变化。[S7、S14] | 先写人物的行为规则，再写规则与关系如何失配 | 不自动禁止快剪，不把女主角写成被动的伤感象征 |
| 《风流一代》 | 多年素材与新拍段落相结合；前两部分在剪辑室从视觉素材形成，少对白、音乐连接多种制式。[S4、S5] | 支持素材先行；先找身体与情感轨迹，再决定叙事 | 不是所有素材都来自同一种方法，也不应强制统一画幅/音质 |

## 选择参照

- 写现场中的小人物：可参考《小武》《任逍遥》的具体行动与在场方式。
- 写群体与长时段变化：可参考《站台》的历史观察距离。
- 写人造空间、媒介和内心：可参考《世界》。
- 写寻人、迁移与关系结果：可参考《三峡好人》《江湖儿女》。
- 写个人记忆与口述：可参考《二十四城记》。
- 写强冲突：可参考《天注定》及《江湖儿女》的类型方法。
- 写跨年代关系：可参考《山河故人》。
- 整理多年材料：可参考《风流一代》的素材先行路径。

这些是任务选择提示，不是新的导演流派分类。不要求一个项目使用全部路径。

## 版本与事实

本表省略存在“制作/首映”口径差异的年份，也不列具体镜头数。若研究需要年份、章节日期、画幅数值或某段精确切点，按最终影片版本另核。
