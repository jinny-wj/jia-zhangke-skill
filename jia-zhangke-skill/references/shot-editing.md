# 镜头与剪辑：何时继续看，何时切换

先看贾樟柯怎样组织人物、空间与时间，再选择剪辑工具。下文把**作品与导演创作谈**、**本技能的创作迁移**分别标明；具体片段分析需取得可看的版本。

## 从作品出发：四种镜头组织

| 特点 | 影像里的组织方式 | 资料归属 | 本项目可以怎样用 |
| --- | --- | --- | --- |
| 完整的生活时间 | 等待、劳动、僵局持续在镜头里；观众可在同框信息间选择观看 | 《小武》《站台》创作谈及观看自由，S1、S2 | 让进出画、前后景与声音逐步改变关系，再确定切点 |
| 不同的摄影距离 | 《小武》较多手持带来现场参与；《站台》较多远景/全景保持历史观察距离 | 导演对两片的比较，S1 | 为当下现场选择贴近身体，为群体与环境选择后退观察 |
| 场内持续与场间省略并存 | 一次相处可保留过程，跨场叙事可跳过多年，让关系变化重新显现 | 《山河故人》的时间省略，S3 | 省略解释，以语言、身体、物件和空间提示经过的时间 |
| 声音与材料共同组织时间 | 音乐连接不同画幅、质感与声音制式；类型/动作段落也可改变长短镜头节奏 | 《风流一代》S4、S5；《江湖儿女》动作设计S7 | 先找情感线与动作信息，再决定材料连接或节奏变化 |

S 编号及证据层级见[来源](sources.md)。这些是分属不同作品的方法，不必在同一短片里全部采用。

## 先拆开三个概念

- **长镜头**：一个镜头持续较久，讨论时间。
- **远景/全景**：画面容纳身体和环境，讨论景别。
- **固定镜头**：摄影机位置与方向保持稳定，讨论运动。

三者可以组合，也可以各自独立。一个手持近景也可以是长镜头；远景可以很短；固定镜头内可以发生高强度冲突。“慢镜头”通常指升格慢动作，不要拿它代称长镜头。

## 人物怎样处在环境中

构图先处理身体与空间的关系：谁能靠近门口，谁被留在后景，人物离开后哪个位置空出来，前景劳动与后景变化如何同时可见。固定、手持、摇镜或近景是实现这一观看关系的工具。

以下表格与后面的 12 种切换是**原创项目的通用实现工具**，不作为导演专属特征或使用频率的结论。

### 观察位置与机位选择

| 选择 | 有用的情境 | 画内要组织什么 | 风险与修正 |
| --- | --- | --- | --- |
| 后退的固定全景 | 人与空间、群体规则、等待 | 前后景、出入口、人物距离、空间限制 | 信息太远时调整走位或景别，不靠解释旁白 |
| 跟随身体的手持 | 进入街道、穿行、现场事件 | 人物移动、视线和环境阻碍 | 晃动不等于真实；确保关键动作可看清 |
| 有动机的摇镜 | 新声源/人物出现、同场关系转移 | 注意力由 A 转到 B 的过程 | 不为给空镜增加活力而反复摇 |
| 缓慢跟移 | 路径与环境逐步显露 | 起点/终点、遮挡变化、同行或分离 | 预算不支持时改走位或固定构图 |
| 中景/双人同框 | 身体交流、工作任务、关系变化 | 两人距离、先后动作、谁看谁 | 不强制每句对白正反打 |
| 近景/特写 | 远处无法读清的决定或关键动作 | 信息必要性、与整体空间的关系 | 不把每次情绪都转成脸部特写 |
| 空间余留/空镜 | 人离开后的持续生活或空间变化 | 与前场有关的声音、物件、痕迹 | 删除没有作用的“破旧建筑合集” |
| 正面肖像/口述 | 个人记忆、讲话、停顿 | 呼吸、措辞、目光、身体变化 | 不把所有沉默剪掉，也不无理由延长 |

若需要具体焦距、快门或色温，根据场地、传感器、收声与光线设计，并写“本项目建议”。现有资料不支持一套固定的“贾樟柯参数”。

## 长镜头的内部设计

先写起始状态和结束状态，再写中间如何改变。变化可以来自人物、空间或声音，不一定是大剧情：

| 变化来源 | 可拍示例 | 观众读到什么 |
| --- | --- | --- |
| 人物动作 | 把工牌摘下，又挂回去 | 想离开与暂时留下 |
| 人物距离 | 两人一起走，后者停下，前者没有回头 | 关系失去同步 |
| 前后景 | 前景收拾桌子，后景灯逐盏熄灭 | 私人动作处于公共结束时间中 |
| 画外声音 | 候车时广播更改发车安排 | 未出现在画内的规则改变行动 |
| 使用中的物件 | 收起第二只杯子，只留下第一只 | 从等待两人变成接受独处 |
| 观看路径 | 看手机、看门口、把手机放下 | 期待转为决定 |

把这些写成镜头表中的动作节点。排练确认时间：等待是否让观众感到具体压力、变化是否读得出。若重复动作只增加秒数，删掉或换成有用途的细节。

## 切点的判断顺序

1. 本镜头要让观众理解的空间、动作或关系，是否已足够清楚？
2. 继续看是否还有新的信息、情绪变化或有意义的持续时间？
3. 下一个镜头新增什么，为什么此刻需要它？
4. 切前、切后分别听到什么？声音延续是否暗示同一时空？

四个问题不要求机械套表，但切点必须有可说明的用途。对话说完一行不是必然切点；动作做完也可以保留余留，前提是余留仍有作用。

## 实现工具：12 种可选切换

以下都是可选剪辑工具；不声称贾樟柯专用或全部高频。

| 方法 | 在什么时候用 | 原创切点设计 | 要保持的清晰度 |
| --- | --- | --- | --- |
| 继续不切 | 同场关系仍在变化 | 拒绝之后继续看他收回伸出的手 | 余留不能变成填时长 |
| 关系变化后硬切 | 一次选择已改变当前处境 | 他独自关门，切到门外仍营业的街面 | 切后提供更大空间或后果 |
| 关键动作切 | 需要看清行动中的决定 | 从两人全景切到递回钥匙的手 | 明确动作与原空间的联系 |
| 空间转移硬切 | 离开、到达或路径断裂 | 离开工作间，切到下一个可用场地 | 保留行进方向/位置线索，或明确有意断裂 |
| 时间省略 | 过程可省，后果重要 | 登车前的犹豫，切到到达后握着同一袋子 | 给足时间/地点线索，不伪装为无缝连续 |
| 空间余留再切 | 人走了，环境还在运行 | 人出画，机器继续响，待其离开被确认后切 | 余留需与人物处境相关 |
| 声音先行（J-cut） | 下场声音先改变观看预期 | 先听夜班报时，再看人物所在房间 | 说明声音来自下场，勿混成同场事实 |
| 声音延续（L-cut） | 前场声音在切后留下感受 | 电话中的迟疑延续到握紧的工牌 | 若跨时空，区分真实延续与主观回声 |
| 声音桥 | 连接不同时段/空间或素材 | 相似的机器节拍连接两处劳动现场 | 不暗示原本无关素材属于同一事件 |
| 物件/姿态呼应 | 时间变化中保留关系记忆 | 过去提着袋子离开，后来用同一袋子收旧物 | 变化必须可读，不能只做漂亮匹配 |
| 长短镜头组合 | 冲突信息与整体调度都重要 | 保留冲突全景，插入必要的近处动作，再回整体 | 短镜头服务可读性，不任意破坏动作方向 |
| 叠化、跳切或载体突变 | 压缩、记忆、材料差异需要被感到 | 保留用户档案的画幅差异，直接切入新素材 | 写清意图；不把这种效果命名为导演固定公式 |

《江湖儿女》访谈中，导演描述过将某动作段落设计为长镜头与短镜头组合。[S7] 这支持技能采用节奏变化的创作选择，不是本轮对最终影片的逐镜头核验；不能把快剪或特写自动判为“不像贾樟柯”。

## 声音表独立于镜头表

每场至少考虑底声、人物任务声、画外事件、对白/音乐的位置。并非每一类都必须存在。

| 声音层 | 需要写明 |
| --- | --- |
| 环境底声 | 空间的安静程度、持续声、距离、是否贯穿切点 |
| 人物任务声 | 衣物、脚步、工具、门、包装袋；哪个动作需要读清 |
| 画外事件 | 来自哪里、是否改变行动、观众何时见到声源 |
| 对白/设备声 | 本人说、电话、广播或扬声器；谁能听到 |
| 音乐 | 现场播放还是后期配乐；年代与功能；起止点 |
| 安静/声音减少 | 少了哪一层声，为什么此时变化，不能默认绝对无声 |

对白不清楚时先判断它是否是关键叙事信息。不能以“纪实感”为理由掩盖必须听懂的话，也不能把有意义的现场声全部清掉。

## 短片与竖屏

短片承载有限的观察时间。30 秒作品可以只拍一次动作从犹豫到决定；不需要十年跳跃。竖屏仍可用门框、前后景和纵向距离呈现人物/环境关系；别为了全景假设必须横屏或无人机。

如需规划秒数，把每镜动作排练的实际时间作为依据；首版写估计值并让合计符合用户片长。估计值不是导演实测参数。

## 对已有素材的剪辑诊断

分别看画面、只听声音，再一起回看，记录具体可定位的问题：信息看不清、空间方向冲突、等待没有变化、音乐掩盖行为、重复镜头没有新增意义。只分析提供的片段。没有视频时只能审剧本/镜头表，不给虚构时码。
